# Assessment Mapping

This project covers the assessment's mandatory functional areas: authentication,
project CRUD, task CRUD, dashboard statistics, search/filtering, responsive React UI,
validation/error handling, PostgreSQL relational storage, bcrypt password hashing,
JWT authentication, protected routes, ownership authorization, rate limiting,
REST API endpoints, OpenAPI documentation, README, environment documentation and ER schema.

The assessment specifies React/Next.js for frontend, Node.js with Express/NestJS for
backend, PostgreSQL/MySQL for database, and requires secure authentication,
authorization, validation, safe database access and authentication rate limiting.

Always describe the actual source implementation accurately during the interview.
